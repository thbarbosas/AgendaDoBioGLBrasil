# Agenda do BioGL Brasil

Painel de feiras, fóruns e congressos onde a Supergasbras pode apresentar o BioGL (gás liquefeito renovável com certificado ISCC PLUS) para empresas dos segmentos residencial, comercial, industrial e agronegócio.

Site: https://thbarbosas.github.io/AgendaDoBioGLBrasil/

- `index.html`: o painel
- `eventos.json`: os eventos, atualizados automaticamente todos os dias às 7h49 e às 13h49 (horário de Brasília)
- `mapa.json`: o mapa do Brasil

Newsletter semanal (segundas, 8h): https://tally.so/r/VpGra6

Desenvolvido por Thiago Barbosa da Silva.
